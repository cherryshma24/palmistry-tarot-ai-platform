# Dataset Report

## 1. Overview

The Palmistry & Tarot Intelligence Platform uses datasets for the Tarot Intelligence and Palm Analysis modules.

The datasets support computer vision, machine learning, tarot information, and AI-assisted interpretation.

---

## 2. Tarot Dataset

The Tarot module uses a dataset containing the traditional 78 Tarot cards.

### Dataset Components

- 78 Tarot cards
- Major Arcana
- Minor Arcana
- Card names
- Card images
- Suit information
- Keywords
- Traditional meanings

The Tarot dataset provides structured card information for the AI interpretation layer.

---

## 3. Palm Analysis Dataset

The Palm Analysis module uses a palm-line recognition dataset for computer vision and pose-based model development.

The Roboflow palm-lines dataset contains:

- 621 images
- 2,484 annotated instances
- 4 palm-line classes

### Palm Line Classes

| Class | Description |
|---|---|
| Fate | Fate line |
| Head | Head line |
| Heart | Heart line |
| Life | Life line |

5. Palm Dataset Structure

The dataset is organized into training, validation, and testing data.

The YOLO configuration defines the dataset paths and class information required for model training and evaluation.

6. Model Training

The project uses the Ultralytics YOLO pose framework for palm-line model development.

The training process includes:

Dataset preparation
Annotation verification
Dataset configuration
YOLO pose model initialization
Model training
Validation
Performance evaluation

The training script is:

backend/train_palm_pose.py

The project uses a YOLOv8 Nano Pose model as the base model.

Large trained model files are excluded from GitHub to keep the repository lightweight.
